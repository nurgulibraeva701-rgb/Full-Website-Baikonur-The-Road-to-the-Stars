# Baikonur: The Road to the Stars
A responsive 5-page website about the Baikonur Cosmodrome (student endterm project).

## Pages
index.html (home, launch animation), missions.html (filter + modal), gallery.html (filter, lightbox, carousel), history.html (timeline + accordion), contact.html (validated form)

## Technologies
HTML5, custom CSS, Bootstrap 5.3 (grid, navbar, carousel, accordion, modal), JavaScript, jQuery 3.7 (animate, fadeIn/fadeOut, slideDown/slideUp)

## Run
Open index.html. Internet is needed for Bootstrap, jQuery, Google Fonts and Unsplash photos (each photo has a colour fallback if it fails to load).
